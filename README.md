# Rogue 1980 Practice

纯 ASCII 地牢游戏，用 C# 从零实现，致敬 1980 年的 Rogue。

这是一个学习项目：目标不是做商业游戏，而是用一个"小而完整"的项目
包含：练 C sharp的集合与泛型、模式匹配、可空引用、单元测试、项目分层；游戏基础的 人物设定，怪物设定，保存与读取，随机地图 核心设计。

- 纯字符终端，不依赖任何图形库
- 回合制：一次按键 = 一个动作。本质是棋盘类游戏
- 没有经验、鉴定、秘密门和陷阱；成长只靠金币

## 存档机制
- 核心逻辑：退出就存档，进入就删档

- 地图保存方式：
  读取 LevelData
    → new Level(80, 22)
    → 把 Rows 的每个字符 Set 回网格
    → 把 Rooms / Monsters / Items 加回去
    → 恢复 Seen
    → _levels[3] = 新的 DungeonLevel
    → _current = _levels[3]

- 存档内容：角色信息，游戏版本，地牢层数，地牢样貌，回合（turn）

## 物品

| 符号 | 物品 | 效果 |
| --- | --- | --- |
| `!` | 治疗药水 | 恢复 `2d8` HP，最多带 6 瓶 |
| `?` | 传送卷轴 | 随机传送到本层可走位置 |
| `%` | 食物 | 恢复 500 点饥饿值 |

## 金币升级

按 `u` 打开升级菜单，不消耗回合：

| 项目 | 效果 | 价格 |
| --- | --- | --- |
| 磨剑 | 剑 +1 伤害 | `40 × (当前等级 + 1)` |
| 加固护甲 | AC +1 | `40 × (当前等级 + 1)` |
| 买药水 | +1 瓶，上限 6 | 25 |
| 买食物 | +1 份，上限 9 | 15 |
| 增加最大 HP | +2 MaxHp | 60 |

玩家初始装备长剑和链甲，不需要捡装备，也没有换装操作。

## 设计说明

- **规则与界面分离**：`Rogue.Core` 不知道终端的存在，所以规则可以用测试直接验证。
- **帧缓冲 + 差分刷新**：每帧先在内存里画好 80×24 个字符，再只把变化的格子用 ANSI 序列写到终端，避免闪烁。
- **一格一字符**：地图是 `char[,]`，1 格 = 1 个字符。游戏内文本一律 ASCII。
- **回合制**：移动、攻击、使用物品、等待都会推进一回合；怪物在回合末行动，饥饿也在同一处结算。
- **存档**：退出时写入 `~/.rogue1980/save.json`，下次启动自动读取并删除（永久死亡）；排行榜在 `~/.rogue1980/scores.json`。
