# Rogue 1980 Practice

纯 ASCII 地牢游戏，用 C# 从零实现，致敬 1980 年的 Rogue。

这是一个学习项目：目标不是做商业游戏，而是用一个"小而完整"的项目练 C#——
集合与泛型、模式匹配、可空引用、单元测试、项目分层，都在这里有真实的用武之地。

- 纯字符终端，不依赖任何图形库
- 回合制：一次按键 = 一个动作
- 简化版：没有经验、鉴定、秘密门和陷阱；成长只靠金币

## 环境要求

- .NET SDK 10.0 或更高（`global.json` 锁定 10.0.401）
- 终端至少 80 列 × 24 行，支持 ANSI 颜色
- macOS / Linux / Windows Terminal

## 快速开始

```bash
git clone https://github.com/john-aston/Rogue-1980-practice.git
cd Rogue-1980-practice
dotnet run --project src/Rogue.Cli
```

macOS 也可以直接双击仓库根目录的 `play.command`。

## 操作

| 按键 | 动作 |
| --- | --- |
| 方向键 | 移动 |
| `Enter` | 站在 `<` 上楼 / `>` 下楼 |
| `q` | 喝治疗药水 |
| `r` | 读传送卷轴 |
| `e` | 吃食物 |
| `u` | 花金币升级 |
| `.` | 等待一回合 |
| `?` | 帮助 |
| `Esc` / `Ctrl+Q` / `Ctrl+C` | 保存并退出 |

## 物品

| 符号 | 物品 | 效果 |
| --- | --- | --- |
| `!` | 治疗药水 | 恢复 `2d8` HP，最多带 6 瓶 |
| `?` | 传送卷轴 | 随机传送到本层可走位置 |
| `%` | 食物 | 恢复 500 点饥饿值 |
| `*` | 金币 | 踩上去自动拾取，用于升级 |
| `,` | Amulet of Yendor | 第 26 层，带回第 1 层通关 |

没有鉴定：捡起来就知道是什么。

## 金币升级

按 `u` 打开升级菜单，不消耗回合：

| 项目 | 效果 | 价格 |
| --- | --- | --- |
| 磨剑 | 剑 +1 伤害 | `40 × (当前等级 + 1)` |
| 加固护甲 | AC +1 | `40 × (当前等级 + 1)` |
| 买药水 | +1 瓶，上限 6 | 25 |
| 买食物 | +1 份，上限 9 | 15 |
| 增加最大 HP | +2 MaxHp | 60 |

玩家初始装备长剑和链甲，不需要捡装备，也没有换装操作。

## 设计说明

- **规则与界面分离**：`Rogue.Core` 不知道终端的存在，所以规则可以用测试直接验证。
- **帧缓冲 + 差分刷新**：每帧先在内存里画好 80×24 个字符，再只把变化的格子用 ANSI 序列写到终端，避免闪烁。
- **一格一字符**：地图是 `char[,]`，1 格 = 1 个字符。游戏内文本一律 ASCII。
- **回合制**：移动、攻击、使用物品、等待都会推进一回合；怪物在回合末行动，饥饿也在同一处结算。
- **存档**：退出时写入 `~/.rogue1980/save.json`，下次启动自动读取并删除（永久死亡）；排行榜在 `~/.rogue1980/scores.json`。

## 已知限制

- 读档后随机数会重新播种，后续战斗的随机结果不会和未中断的存档完全一致。
- 屏幕固定 80×24，调整窗口大小不会自适应。
- 游戏内文本一律 ASCII；中文只出现在代码注释和 README。
- 只有一把武器和一件护甲，开局即装备，靠金币升级。
- 存档只在正常退出时写入；强制关终端不会保存。
